## 附录一：企业自建 GPU 机房 vs 云端商业 API 5年全生命周期 TCO 精密对比测算表

企业在做 AI 预算时，最大的幻觉就是把“买 8 张显卡的钱”等同于“自建算力的总成本”。本表按标准 IDC 机房建设规范与 5 年折旧周期，还原真实企业 TCO（Total Cost of Ownership）。

### 1. 测算基准模型假设
- **企业规模**：年营收 1~3 亿人民币，中型制造/跨境/科技公司，常态并发需求约 50~100 QPS（日均处理约 500 万~1000 万 Token，峰值 100 QPS）。
- **自建方案（On-Premise）**：采购 2 台 8 卡 H800 / 910B 级高密度 GPU 服务器（共 16 卡），配置 400G InfiniBand 交换机，自建或托管于 T3 级标准机房。
- **云端商业 API 方案（Cloud Serverless API）**：采用 DeepSeek-V3/R1 / 智谱 GLM-4 / 阿里 Qwen 等商用云端模型 API，按实际 Token 用量及 Prompt Caching 折扣付费。

### 3. 自建 vs 云端 决策分水岭速查公式

当且仅当满足以下**全部三个条件**时，自建机房才有经济学意义：
1. **日均稳定 Token 吞吐量** 达到 **20 亿 Token 以上**，且白天夜晚算力利用率均高于 85%（无波谷浪费）；
2. **法律合规硬性约束**：属于《数据安全法》核心数据或《反间谍法》涉密军工/金融核心交易，外网断绝物理连接；
3. **团队拥有常态化 LLMOps 研发能力**：无需外部高价交付团队，自身具备 Triton 算子优化与显存碎片整理能力。

> **结论**：凡年利润低于 3000 万的企业，自建私有化机房 99% 沦为向供应商与机房电力公司利益输送的负资产，建议 100% 走公有云端 API 加端到端客户端加密方案。

## 附录二：生成式 AI 算法备案与安全评估全流程自查对照表

依据《互联网信息服务深度合成管理规定》《生成式人工智能服务管理暂行办法》及《人工智能生成合成内容标识办法》（2025年9月1日生效），企业在上线面向公众的 AI 产品前必须完成以下 8 大合规闭环。

| 审核模块 | 重点自查指标 | 法律法规依据 | 常见被驳回/处罚红线 | 昆仑增长建议交付物 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 算法基础信息** | 算法名称、应用场景、作用机制、模型基座来源 | 《互联网信息服务算法推荐管理规定》第十九条 | 填报逻辑与实际业务脱节；隐瞒境外调用闭源底座 | 《算法安全自评估报告》第 1-3 章节 |
| **2. 训练语料合法性** | 语料版权、反爬合法性、商业使用权、敏感词清洗 | 《生成式人工智能服务管理暂行办法》第七条 | 语料包含盗版书籍、未经授权的社媒用户私信、违规抓取数据 | 《训练数据来源合法性承诺书》+ MinHash清洗日志 |
| **3. 内容安全与过滤** | 敏感词双向拦截（Prompt与Completion）、分类分级 | 《网络安全法》第十二条、四十七条 | 输入涉政/涉黄绕过率高于 0.05%；无实时熔断机制 | 敏感词库（包含1.2万关键词）+ 多模态兜底模型 |
| **4. 水印与显隐式标识** | 文本/图像/音频/视频显式标识与隐式盲水印嵌入 | 《人工智能生成合成内容标识办法》（2025年9月1日） | 图像无可见水印；下载文件抹除 C2PA 元数据 | 显式“AI生成”浮水印 + C2PA/LSB 隐式防伪嵌入代码 |
| **5. 真实身份认证** | 手机号短信验证、微信/支付宝实名鉴权、IP追溯 | 《反电信网络诈骗法》第十五条 | 允许匿名调用 API；允许虚拟号注册 | 用户实名认证系统截图 + 手机号风控接口调用记录 |
| **6. 个人信息保护** | 用户 Prompt 隐私协议、禁止作为公共训练、注销通道 | 《个人信息保护法》第十三条、二十四条 | 默认抓取用户输入进行微调；未提供清空上下文/注销入口 | 《生成式AI服务用户服务协议》+ 一键销毁数据接口 |
| **7. 意识形态与防沉迷** | 核心价值观对齐评估、未成年人时长与防沉迷限制 | 《未成年人网络保护条例》第三十六条 | 对争议历史/意识形态问题回答出现政治偏离；未成年深夜可用 | 1000条对齐测试集（Alignment QA）及格率100%测试报告 |
| **8. 应急处置与日志保存** | 6个月全量双向明文日志、公安接口、一键下线熔断 | 《网络安全法》第二十一条 | 日志仅存 30 天；遇网信协查无法提供溯源 UID 和 IP | WORM（只读不可篡改）日志归档架构方案（保留180天） |
